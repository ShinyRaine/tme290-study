TME290 / FIM764 Autonomous Robots — 2026年8月补考

考试日期：2026-08-25（周二） · 全部判断题（True/False）· 答错不扣分 · 及格线约 75%（60 题对 45 题）

备考策略：不背闪卡，精读《原理复习手册》的因果链 + 真题/模拟卷检验

一、学习方法：读原理 → 自己复述 → 真题检验 → 短时高频重复

全部考点已浓缩进《知识手册》（8 个知识块 + 术语表，每块 = 一段原理叙述 + 三年真题演练）。不用再读课件 PDF。

每个知识块三步（约 25 min）：

  1. 读原理（10-15 min）：把那段“为什么会这样”的因果链读懂。
  2. 合上书自己复述（5 min）：用自己的话把原理讲一遍（不是背表格、不是画图，就是顺一遍“因为…所以…”）。讲不顺的地方就是漏洞，翻回去再读。
  3. 做该块“真题演练”（10 min）：三年真题逐条判 T/F、对官方答案，错的回到原理再看一眼。
专治遗忘的关键：短时、高频、间隔。 记忆弱的人靠的不是“记得牢”，是“忘之前又见了一面”。宁可每天 30-40 min、一周 4 次，也不要一次 3 小时、一周一次。每次开始前，先花 5 分钟快过上一次学的块（滚动复习），再学新的。

总时间预估：约 18 小时

项目时长
通读+理解全部 8 个知识块原理（第一遍）~5 h
三套真题：逐条对官方答案、弄懂每道错题~3 h
滚动重复：自测原理 + 重做真题（多轮，专治遗忘）~8 h
考前收尾（错题 + 附录速览 + 钓鱼清单）~2 h

重点：记忆弱 ≠ 要更多总时长，而是把这 ~18h 拆成更多次、间隔开。真正决定及格的是那两个行为习惯（不留空、can 陷阱），不是学时。

二、必背「钓鱼题」清单（历年反复挖的坑）

记事实，不记句子。出题人每年把同一事实换措辞或反着说来钓鱼，下面每条写的都是“正确的事实本身”。

  • φ̇ = (vR − vL) / 2R —— 分母是 2R 不是 R；V = (vR + vL)/2 —— 没有 R
  • docker run 创建并运行的是 container，不是 image
  • Alpine 镜像比 Ubuntu 小（两个方向都考过）
  • 多阶段构建：build 工具只在 builder 阶段，不进最终镜像；测试在 build 时跑
  • libcluon = 进程间通信库（三年都考，是对的）
  • 微服务：一个服务只做一件事；统一通信协议；方便 OTA 和 CI/CD
  • Kalman：process model 描述运动，不是“另一种传感器模型”；Kalman gain 是权衡模型/观测的信任度，不能提高传感器频率；KF 可以在线跑，不需要录好的数据；先 Predict 后 Update
  • 轮速↔V/φ̇ 的运动学关系是线性的 → 标准 KF 可用；但状态向量取 [x, y, φ]（含朝向角）时位置更新含 cos/sinφ 非线性 → 要 EKF（动力学模型同理）
  • FSM 描述行为间转移（对）；FSM 不会自动调参（错）；Braitenberg 车 ≠ FSM
  • BBR 灵感来自动物行为学 ethology，不是心理学 psychology
  • Subsumption：高层抑制低层输出、并行、可增量扩展
  • 交叉编译：在 amd64 (GitLab CI) 上编出 arm64 (RPi/Kiwi) 的二进制；SSH ≠ 交叉编译
  • 视觉参数不要硬编码；调感知参数用 data replay 最高效，调运动控制用实物/仿真
  • Two-point 转向模型：near point + far point，输出是转向速率（三年原句必考）
  • PID：D 项抑制振荡；转向控制里 I 项不是最重要的
  • 相机：Bayer 阵列绿色最多；rolling vs global shutter；intrinsic（像素→相机坐标）vs extrinsic（相机→车身）
  • 2026 新增：Walter 的 Tortoise、Shakey；PLD/FPGA 极快低功耗、微控制器无操作系统但实时性强、CPU 实时性受限；OTA = 远程部署软件（不是“读回性能数据”）

三、日程（到 8月25日，节奏 = 每次 30-40 min、每周 3-4 次）

摸底已完成（40/60）。按“先学 → 通关 → 保持”三段走。日期是弹性的，核心是保证次数和间隔，别攒到一起。

阶段 A · 学习（7月上中旬，约 2-3 周，8h）— 按优先级过完 8 块

每次挑一块，走“读原理 → 合书自己复述 → 做该块真题演练”。顺序按薄弱 + 分值：

  1. 软件工程（错最多、分值最大）：Docker/镜像容器、多阶段构建、微服务、CI-CD/OTA/git、交叉编译、SSH
  2. 计算硬件（4 题全错）：PLD / 微控制器(裸机→实时) / CPU / GPU
  3. 决策 FSM/BBR/Braitenberg/符号AI/进化/ANN
  4. Kalman：Predict→Update、两模型、gain、线性→标准KF / 含 φ 非线性→EKF
  5. 运动学：草稿纸推 V=(v_R+v_L)/2、φ̇=(v_R−v_L)/2R、位置=速度积分
  6. 传感器 / 历史 / 控制转向 / 仿真 / Dijkstra（较轻，一起过）

每次开头先花 5 分钟快过上一次学的块（滚动复习）。

阶段 B · 通关（7月下旬，约 1 周，3h）— 三套真题

  • 完整重做 2024 → 2025 → 2026 三套（计时约 30 min/套），逐条对官方答案。
  • 错题一律回手册对应块看原理，不要只记答案。
  • 目标：2026 卷稳定 50+/60。

阶段 C · 保持（8月—考前，约 3-4 周，5h）— 最重要，专治遗忘

  • 每周 2-3 次、每次 30 min：快速自测手册（每块合书复述原理）+ 轮流重做一套真题 + 扫一遍手册《附录·30分钟速览》。
  • 8月17日前后（考前一周）：把 2026 卷第三次做一遍，应稳定 50+；同时闭卷做一遍全新措辞的模拟卷。
  • 8月23日（考前 2 天）：三套真题只看还错的题 + 通读钓鱼清单。
  • 8月24日（考前 1 天）：只快过《附录速览》+ 最弱的 1-2 块，早睡。

考场策略（比学时更能提分）

  • 每题必答、绝不留空（不扣分）——上次 12 分丢在留空，这一条直接从 40 提到 ~52。
  • 见到 good idea / best / should → 按“最佳实践”判；见到 can → 问“要成立是不是得靠歪招？是 → FALSE”。
  • 运动学题：草稿纸从 ICR 推 5 行核对系数，别凭印象。
  • 绝对词（exactly / always / all / automatically）先标记、回头细想。目标 ≥ 50/60。

四、风险提示

  • 出题趋势是题量变大、覆盖变广（33 → 46 → 60），2026 年新增的历史/硬件/传感器块大概率保留——不能跳过。
  • 若补考卷恢复“答错倒扣”规则（2024年8月曾如此），考前务必看清卷首计分说明，再决定不确定题是否留空。
